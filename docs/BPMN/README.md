# BPMN — LOSTTECH

> Documentação e modelagem de processos de negócio utilizando BPMN (Business Process Model and Notation).

---

## Objetivo

O diretório **BPMN** centraliza os diagramas e documentos relacionados à modelagem dos processos da LOSTTECH.

A utilização de BPMN permite representar visualmente processos, responsabilidades, decisões, integrações e fluxos operacionais de forma padronizada.

---

## Finalidades

Os diagramas BPMN são utilizados para:

- Mapear processos existentes
- Definir novos processos
- Identificar etapas e responsáveis
- Documentar regras de negócio
- Identificar gargalos e pontos de melhoria
- Padronizar operações
- Apoiar o desenvolvimento de sistemas
- Facilitar automações
- Documentar integrações entre sistemas
- Auxiliar na análise e evolução dos processos
